# dot-tmux

My tmux configuration and the scripts it uses.

## Install

```sh
git clone https://github.com/klaskow/dot-tmux.git ~/dot-tmux
ln -s ~/dot-tmux/tmux.conf ~/.tmux.conf
mkdir -p ~/.local/bin
ln -s ~/dot-tmux/bin/* ~/.local/bin/
```

Each script describes its usage and requirements at the top of the file.
